# 1ª Avaliação Presencial - Laboratório FullStack

API REST desenvolvida em Spring Boot 3.x para gestão de Funcionários e Departamentos.

## Como Executar

- **Via IntelliJ:** Executar a classe `DemoApplication.java`.
- **Via Terminal:** `mvn spring-boot:run`

A aplicação roda em `http://localhost:8080`.
